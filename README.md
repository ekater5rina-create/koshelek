# Кошелёк

Приложение для учёта наличных и семейного бюджета, которое работает офлайн
и ставится на домашний экран айфона как обычное приложение.

**Открыть:** https://ekater5rina-create.github.io/koshelek/

## Что умеет

- Ввод операции в два тапа: сумма на большой клавиатуре → категория → готово.
- Голосовой и текстовый ввод обычной фразой: «кофе 250», «такси 300 вчера картой»,
  «расход образование обучение 25000». Понимает даты, названия счетов и статей.
- Распознавание кассовых чеков: QR-код читается прямо с фотографии, текст чека
  разносится по категориям построчно.
- Подтверждение перед записью: приложение показывает, как оно поняло операцию,
  и ждёт согласия. Ничего не сохраняется молча.
- Несколько счетов и переводы между ними.
- Отчёты по месяцам: кольцевая диаграмма, доли категорий, год столбиками.
- Лимиты по категориям на месяц.
- Цели накоплений с планом: сколько откладывать в месяц, неравномерный график
  с поправкой на сезонность и список категорий, где взять недостающее.
- Регулярные платежи: находятся в истории автоматически, отмечаются в один тап
  и учитываются в прогнозе расходов до конца месяца.
- Фонд нерегулярных трат: сколько резервировать на машину, дачу, ремонт и страховку.
- Импорт из таблицы «Планировщик семейного бюджета» (CSV), экспорт в CSV,
  резервные копии с напоминанием.

## Приватность

Все данные хранятся только в браузере вашего устройства. Ни операции, ни фотографии
чеков никуда не отправляются — распознавание QR работает локально. В этом репозитории
финансовых данных нет: свои операции вы загружаете сами через «Ещё» → «Восстановить
из копии» или «Импорт файла „Планировщик бюджета“».

Поскольку данные живут только на устройстве, делайте резервные копии — приложение
напоминает об этом раз в две недели.

## Установка на айфон

1. Откройте ссылку выше **в Safari** (в других браузерах установка недоступна).
2. «Поделиться» → «На экран „Домой“».
3. Запустите с иконки один раз при интернете — приложение сохранит себя в память телефона.
4. Дальше работает без интернета, в том числе в авиарежиме.

## Устройство

Обычные HTML, CSS и JavaScript без сборки и внешних зависимостей, кроме
[jsQR](https://github.com/cozmo/jsQR) (Apache-2.0) для чтения QR-кодов.

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | разметка и оформление всех экранов |
| `data.js` | справочник категорий и хранилище |
| `app.js` | экраны, ввод, отчёты, импорт и экспорт |
| `nlp.js` | разбор фраз и голосовой ввод |
| `receipt.js` | чтение QR чека и разбор его текста |
| `goals.js` | цели и алгоритмы советов |
| `plans.js` | регулярные платежи, фонд, резервные копии |
| `planner.js` | импорт CSV «Планировщика семейного бюджета» |
| `sw.js` | офлайн-режим |
